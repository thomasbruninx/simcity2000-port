# Random terrain (Edit New Map)

Port: `src/simulation/terrain_gen.{h,cpp}` (`generateTerrain`), `Simulation::startNewCity(..., terrain)`, Ctrl+N dialog "Random terrain". Differential test `sc2k-emu-diff terrain`: the whole original generator 0x410430 (progress-window calls stubbed) against the port on 7 parameter sets (including 0 % and 100 % settings, coast and river on and off) on 4 files: **identical** (altitudes, tiles, water flags, census, RNG and LCG states).

Parameters (the dialog's sliders, 0..47 each): hills, water, trees; flags: coast, river. Steps (strings 800..809 are the progress texts):
1. clear: altitudes 0, terrain 0, every tile id 0 (census updated), water flag cleared; rotation 0.
2. **Creating Hills** (0x447040): an 8x8 grid of `rand() % (hills + 11) + 1` seeds every 16th tile, then four midpoint-displacement passes 0x4470E0 (steps 8, 4, 2, 1; outside the map the altitude is `hills + 10`, 0 beyond the high-a edge when there is a coast).
3. sea level = (water + 4) / 8 (at least 4 with a coast or river). **Carving Water**: coast 0x4474C0 (a wandering shore 10..39 tiles deep along the high-a edge, LCG), river 0x447610 (7 tiles wide from a = 127 to 0, drifting columns, LCG).
4. **Smoothing** x2 (0x447380: average with the four neighbours), altitude transform `t = (v + 3) / 2; v = t - 4 >= 4 ? t - 4 : (t - 4 >= 0 ? 4 : t)`, **More Smoothing**, water-level bits cleared.
5. **Reticulating Splines**: cliff limiter 0x446830 (no tile more than one level above a neighbour) and the shore / water fixer 0x4469C0 on every tile.
6. **Adding Forest** (0x446EA0): `trees^2 / 2` clusters of up to 63 random tree tiles (ids 6..12).
7. coast: **Smoothing Coast** (0x4477C0: salt-water flag clean-up, four passes); then `water / 4` **streams** (0x445DF0, 50..177 tiles from random places).
The original then centres the view on tile (64, 64); the new-city setup (docs/simulation/new-city.md) follows.

## Map editor (File > Edit New Map)
`GameUi::enterMapEditor`: the default map gets a generated landscape, the game stops and the panel "Terrain Generation" appears: sliders Hills / Water / Trees (0..47, shown as percent), the Coast and River boxes (strings 791 / 792), **MAKE** (strings 793: a new random landscape from the sliders) and **DONE** (794: start year and difficulty, then the edited landscape becomes the new city; the generator is not run again). Only the terrain tool groups (Landscape, Terrain editor, Terrain) can be selected meanwhile; the status line says "Editing Terrain..." (string 413). While the generator runs, `ZoneHooks::terrainProgress(stage)` reports the step names (strings 801..809: Creating Hills, Carving Water, Smoothing, More Smoothing, Yet More Smoothing, Reticulating Splines, Adding Forest, Smoothing Coast, Tracing Streams; the calls sit where the original calls 0x414E50) and the generator plays sound 529 (0x211, `SOUNDS/529.WAV`) after the altitude transform exactly where 0x4106A6 does. The progress window with its bar and the live preview of the original's dialog 104 are not reproduced.

## Sea level (terrain editor)
`applySeaLevel` (0x445A60, **emulator-identical** on all cities and scenarios for raised, lowered and extreme levels: `sc2k-emu-diff sealevel`): for every tile, land altitude below the level -> water flag, water altitude bits of ALTM set to the level, trees and small objects (ids 6..0xD) removed, XTER = shape + 0x10 (deep) or + 0x20 (shallow beside land, `land + 1 >= level`), 0x10 for shapes >= 0x30; tiles at or above the level that carry the water flag lose it (shape back to the land shape). Raise (0x445D10) / lower (0x445D80) step MISC 912 between 0 and 0x1F and run it. In the port: the "Raise Sea Level" / "Lower Sea Level" buttons of the map-editor panel and the two items of the Terrain editor toolbar group (strings 68 / 69).
